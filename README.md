# Python Application Programming

A complete reference and project suite covering core Python programming, object-oriented software design, data handling, and application development.

## 📌 Module Breakdown

### 1. Introduction to Python: Expressions, Lists, & Tuples
- **Core Syntax & Expressions:** Operators, variables, conditional logic, and control flow.
- **Sequence Types:** Operations, indexing, slicing, and methods for `Lists` (mutable) and `Tuples` (immutable).

### 2. Object-Oriented Concepts
- **Class Fundamentals:** Instantiation, constructors (`__init__`), methods, and instance/class attributes.
- **OOP Pillars:** Encapsulation, abstraction, inheritance (single and multiple), and polymorphism.

### 3. Data Processing
- **File I/O:** Reading, writing, and parsing plain text, CSV, and JSON formats.
- **Data Manipulation:** Filtering, transforming, aggregating, and structuring datasets.

### 4. Business & Web Applications
- **Application Logic:** Automating business processes and script integration.
- **Web Development:** Backend services, RESTful API consumption, and lightweight framework structures.
